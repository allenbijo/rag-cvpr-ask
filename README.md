# RAG-CVPR-ASK

RAG-CVPR-ASK is a Retrieval-Augmented Generation (RAG) system designed to fetch the latest CVPR papers, cache them, and extract relevant data for querying.

## Features
- Automatically retrieves the latest CVPR research papers.
- Caches fetched papers for efficient access.
- Enables querying and extracting key information from the papers.
- Enhances research workflows by providing up-to-date insights.

## Overview
This project leverages RAG techniques to enhance information retrieval from CVPR publications. By maintaining a local cache, it reduces redundant API calls and speeds up access to relevant papers.
